🎯 Table Drag & Resize Feature Demo

📋 Overview

This feature adds professional table manipulation capabilities to your WYSIWYG editor, similar to Froala Editor. Users can resize and reposition tables with intuitive drag handles.

✨ Key Features

🔄 Resize Tables

8 resize handles (4 corners + 4 edges) allow flexible table resizing in any direction.

🎯 Drag to Move

Top drag handle lets users reposition tables anywhere in the editor.

👁️ Visual Feedback

Clear visual indicators show selected state and active operations.

⚡ Smart Constraints

Minimum size limits prevent tables from becoming too small.

📖 How to Use

1. Select a Table

  • Click anywhere on a table in the editor
  • Blue outline and handles will appear
  • Table is now ready for manipulation

2. Resize a Table

  • Corner Handles: Drag to resize both width and height
  • Edge Handles: Drag to resize in one direction only
  • North/South: Adjust height
  • East/West: Adjust width
  • Minimum size: 100px width, 50px height

3. Move a Table

  • Click and hold the top drag handle (⋮⋮)
  • Drag to desired position
  • Release to place the table
  • Table becomes absolutely positioned

4. Deselect a Table

  • Click anywhere outside the table
  • Handles will disappear
  • Table returns to normal state

🔧 Technical Implementation

Service Architecture

The feature is implemented using a dedicated TableHandlerService that manages:

  • Table selection and deselection
  • Resize handle creation and management
  • Drag handle creation and management
  • Mouse event handling for drag/resize operations
  • Content synchronization with the editor

Key Components

  • TableHandlerService: Core service managing all table interactions
  • table-handlers.scss: Comprehensive styling for handles and states
  • EditorContentComponent: Integration point for the feature

Event Flow

  1. User clicks table → selectTable() called
  2. Handles are added to the table DOM
  3. User drags handle → Mouse events tracked
  4. Table dimensions/position updated in real-time
  5. On release → Content change event triggered
  6. Editor content model updated

🎯 Handle Types

Handle Position Function Cursor
nw Top-left corner Resize width & height (northwest) nw-resize
ne Top-right corner Resize width & height (northeast) ne-resize
sw Bottom-left corner Resize width & height (southwest) sw-resize
se Bottom-right corner Resize width & height (southeast) se-resize
n Top edge center Resize height only (north) n-resize
s Bottom edge center Resize height only (south) s-resize
e Right edge center Resize width only (east) e-resize
w Left edge center Resize width only (west) w-resize
drag Top center (above table) Move entire table move

⚙️ Configuration

Minimum Sizes

  • Width: 100px (prevents tables from becoming too narrow)
  • Height: 50px (prevents tables from becoming too short)

Visual Styling

  • Selection Color: #4a90e2 (blue)
  • Handle Size: 8px (corners), 6px (edges)
  • Opacity: 0.8 (resizing), 0.7 (dragging)
